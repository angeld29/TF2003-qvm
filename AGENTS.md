# AGENTS.md

TF2003-qvm: QuakeWorld Team Fortress 2003 server-side mod in C, dual-compiled into a native
shared lib (`qwprogs.so`/`.dll`, `sv_progtype 1/3`) and QVM bytecode (`qwprogs.qvm`, `sv_progtype 2`).
Runs on mvdsv / qwsv262 servers.

## Build

All artifacts go to `_cmake/` (gitignored). `make` wraps CMake; `make help` lists targets.
- `make` / `make qvm` — QVM only (default) → `_cmake/qvm/qwprogs.qvm`
- `make current` — native build for the current host → `_cmake/current/qwprogs.so`
- `make <platform>` — `linux-amd64 | linux-armhf | linux-i686 | windows-x64 | windows-x86`
- `make all` — all 5 platforms + QVM (release); `make clean` — `rm -rf _cmake/`

`q3lcc`/`q3asm` are built automatically from `tools/` at configure time (the prebuilt
`tools/*.exe` are not used by cmake). Cross toolchains live in `tools/cross-cmake/`;
per-platform prerequisites are in BUILD.md.

## Adding a source file

Add it to `SOURCE_LIB` in `CMakeLists.txt` — that feeds both native and QVM builds
(`game.q3asm` is regenerated on configure). Do NOT touch `meson.build`: it is a stale
native-only secondary build, out of sync with `SOURCE_LIB`.

## Syscall plumbing

A new engine call touches three files that must stay in sync:
- `include/g_syscalls.h` — prototypes
- `src/g_syscalls.c` — native trampolines (DLL only)
- `src/g_syscalls.asm` — QVM `equ` numbers (used instead of the .c under `Q3_VM`)

## Compiler/VM constraints (full list in `README.md`)

- 32-bit VM: no `double`; `float` doesn't promote as a param; avoid `short`/`unsigned char`.
- `switch` run-on `case` labels produce unsafe code — each case must break or have no logic before the next label.
- No string arrays in a struct mixed with other types (q3asm puts strings in a separate segment).
- Mac VM is big-endian — don't byte-serialize `int` directly.
- Don't use `map` with `redirectcmd`/`executecmd`/`readcmd`.

## Hard rules

- Do not modify `include/progdefs.h` (auto-generated, "generated by qcc, do not modify") or `include/g_public.h` (engine contract).
- Entity fields via `PROG_TO_EDICT` / `EDICT_TO_PROG` (e.g. `(gedict_t*)->s.v.owner`).
- Map entity tables live in `src/g_spawn.c` (`fields[]`, `spawns[]`); missile spawn requires `g_globalvars.newmis`.
- `GAME_API_VERSION` is in `include/g_public.h` (currently 16); the mod aborts at load if the engine is older (`src/g_main.c`).

## Verification

No tests, no CI — verify by building and running on an mvdsv/qwsv262 server. `pvs.sh`
runs PVS-Studio analysis (optional, needs pvs-studio installed).
